# Creator Systems

Use this skill as a generic thinking layer for daily content planning. It should shape the topic and editorial decision, not become visible in the final copy.

## Core Ideas

- Attention is the scarce asset.
- Writing clarifies thinking and creates leverage.
- Goals need systems, constraints, and feedback loops.
- Sustainable output beats short bursts of intensity.
- Identity and environment shape behavior more than motivation.
- A useful idea should connect inner friction to a practical external pattern.

## Planning Heuristics

- Pick one theme worth saying today.
- Start from a real situation instead of a concept.
- Find the reader's hidden tension.
- Decide what the batch should help the reader notice.
- Use practice only when it naturally follows from the observation.
- Keep platform fit separate from the underlying idea.

## Output Boundary

When used by `xpost-agent`, this skill is only the thinking layer. Final public posts should not mention systems, this skill, prompts, AI, or named creators unless the user explicitly asks for that topic.
